# SMART RETAIL MANAGER

## Project Overview
Smart Retail Manager is a simple Python-based inventory management system designed to manage products in a retail store.
This project helps users add, display, search, update, and delete products. It also provides low stock reports and inventory summaries.

## Project Objectives
- To manage product information easily.
- To maintain product stock records.
- To search products using Product ID.
- To update product details.
- To identify low stock products.
- To calculate total inventory value.

## Technologies Used
- **Programming Language:** Python
- **Data Storage:** Python List and Dictionary
- **Editor:** VS Code

## Features

1. **Add Product**
   - Add new products.
   - Enter Product ID, Name, Category, Price, Stock and Reorder Level.
   - Prevent duplicate Product IDs.
2. **Display Products**
   - Display all available products.
3. **Search Product**
   - Search products using Product ID.
4. **Update Product**
   - Update product name, price and stock quantity.
5. **Delete Product**
   - Delete products after confirmation.
6. **Low Stock Report**
   - Display products whose stock is equal to or below the reorder level.
7. **Inventory Summary**
   - Display total products.
   - Calculate total stock.
   - Calculate total inventory value.

## How to Run the Project

**Step 1:** Install Python on your computer.
**Step 2:** Open the project folder in VS Code.
**Step 3:** Open the terminal.
**Step 4:** Run the following command:
```bash
python main.py
```
**Step 5:** The Smart Retail Manager menu will appear.

## Current Limitations
- Product data is stored temporarily in memory.
- Data will be lost when the program is closed.
- MySQL database connectivity is not implemented yet.
- This is currently a basic console-based application.
